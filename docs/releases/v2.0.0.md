# ☁️ Paper Library v2.0.0: Now with OneDrive

> **Your library, in the cloud you already use.** Paper Library now works with **OneDrive**
> (personal, work or school) as well as **Google Drive**. Same viewer, same highlights inside the PDF,
> same Mendeley-style library. Pick a cloud, and switch any time.

---

## ✨ What's new

### ☁️ Choose Google Drive or OneDrive
The first screen now asks **where your library should live**:

| | Google Drive | OneDrive |
|---|---|---|
| Accounts | Gmail or Google Workspace | Personal (outlook.com, hotmail…), work or school |
| Your own sign-in app | OAuth client in Google Cloud | App registration in Microsoft Entra |
| Highlights | Inside the PDF, new Drive revision | Inside the PDF, new OneDrive version |
| Collections | Drive folders | OneDrive folders |
| Title, authors, year | Hidden file properties | `Paper Library/.paper-library.json` |

### 🔁 Switch back and forth
**Settings → Switch to OneDrive / Switch to Google Drive.**
- Each cloud keeps **its own library, client ID and sign-in**, so switching back is instant. No setup again.
- **Nothing is copied or deleted** when you switch. You just see the other cloud's library.
- Existing users: nothing changes until you switch. Google Drive stays the default.

### 🔐 Private by design, on both clouds
- With OneDrive you register **your own** free Microsoft app, just like the Google client ID.
  The permission you grant belongs to you.
- Sign-in uses Microsoft's **authorization code + PKCE** flow: **no client secret**, and tokens stay
  in your browser's session storage.
- Still **no server, no analytics, no tracking.**

### 🗑️ Delete forever and Empty Trash
Trash used to offer only **Restore**. Now you can remove papers for good, on both clouds:
- Select papers in **Trash** → **Delete forever**, or click **Empty Trash** (or press `Delete` in Trash).
- You always confirm first. It can't be undone, and highlights inside the PDF go with it.
- **Google Drive:** the file is deleted permanently, skipping Drive's trash. Its shortcuts in other collections go too.
- **OneDrive:** Paper Library asks OneDrive to skip its recycle bin. Microsoft allows this for some
  account types only; if yours doesn't, you get a prompt with a button to **open the OneDrive recycle bin**
  and empty it yourself (otherwise OneDrive clears it after about 30 days).

### 📝 Also included: v1.3 Markdown export
Export a paper's highlights and notes as Markdown from the viewer menu or the library's details
panel. Works the same on both clouds.

## 🚀 Getting started with OneDrive
1. Update the extension (below), click the Paper Library icon → **Settings → Switch to OneDrive**
   (or choose **OneDrive** on the first screen).
2. Follow the 5-minute guide: **[docs/SETUP-ONEDRIVE.md](../SETUP-ONEDRIVE.md)**
   - Entra → **App registrations** → **New registration**
   - Account types: **any organizational directory + personal Microsoft accounts**
   - Redirect URI, type **Single-page application**:
     `https://hadmfffnocpeglonjioajbpdfbkbjekf.chromiumapp.org/`
3. Paste the **Application (client) ID** → **Sign in with Microsoft** → **Accept**.

A **Paper Library** folder appears in your OneDrive. Drop PDFs in, or use **Import folder**.

## 🛡️ Network lock: what changed
The Content Security Policy in `manifest.json` still blocks every website except the ones listed.
v2.0.0 adds Microsoft's, used **only when you choose OneDrive**:

| Host | Why |
|---|---|
| `graph.microsoft.com` | The OneDrive API |
| `login.microsoftonline.com` | Microsoft sign-in |
| `api.onedrive.com`, `*.1drv.com`, `*.sharepoint.com`, `*.microsoftpersonalcontent.com` | Microsoft's storage servers. OneDrive sends file downloads and large uploads through short-lived links whose server name varies per account, so these are allowed by domain. |

Check it yourself: `python3 scripts/audit.py` prints **Unexpected hosts: none**.
Details in [SECURITY.md](../SECURITY.md) and [PRIVACY.md](../PRIVACY.md).

## 🧭 Good to know (OneDrive)
- 🗂️ **Don't delete `.paper-library.json`** in your library folder. It holds titles, authors,
  favourites and "also in this collection". Without it, details have to be looked up again.
- 🗑️ **Trash** keeps papers in a hidden `.trash` folder until you restore them, or delete them in OneDrive.
- 🏫 **Work/school accounts** may show *"Need admin approval"* if your organisation restricts apps.
  A personal Microsoft account always works.
- 🔘 The **Open in Paper Library** button exists on drive.google.com only. For OneDrive, open papers from the library.

## 🔧 Under the hood
- New **provider layer** (`js/provider.js`): Google Drive and OneDrive offer the same functions,
  so the viewer and library don't care which cloud they talk to.
- `js/ms-auth.js`: Microsoft sign-in (PKCE, silent renewal, refresh tokens in session storage).
- `js/onedrive.js`: Microsoft Graph. Chunked upload sessions with progress, conflict-safe index
  writes (`If-Match` + retry, so two open tabs never overwrite each other), version-aware saving.
- `scripts/audit.py` understands wildcard hosts in the lock.

## ⬆️ How to update
1. Download **`paper-library-v2.0.0.zip`** below and check it:
   ```bash
   sha256sum -c paper-library-v2.0.0.zip.sha256
   ```
2. Unzip it **over your existing Paper Library folder**.
3. `chrome://extensions` → **⟳** on Paper Library. Close and reopen open Paper Library tabs.

Your Google Drive library, highlights and client ID stay exactly as they are.
